PATCH NOTIFIKASI MAGANG + TAMPILAN LONCENG BARU
================================================
Timpa file berikut (struktur folder sama dengan proyek). Tanpa perubahan database,
indeks Firestore, package.json, maupun app.js. Restart server setelah menimpa.

A. TAMPILAN & PEMBERSIHAN NOTIFIKASI (baru)
  views/partials/notif_panel.ejs     BARU   panel lonceng + CSS + JS (dipakai seluruh halaman)
  views/partials/notif_item.ejs      BARU   satu baris notifikasi (ikon berwarna per jenis)
  views/partials/header.ejs          TIMPA  (hanya blok lonceng: badge ber-id + include notif_panel;
                                             bila header.ejs sudah Anda ubah, ganti blok "<!-- Notifikasi -->" saja)
  views/notifikasi.ejs               TIMPA  halaman penuh, gaya sama + filter "Belum dibaca"
  routes/notifikasi.js               TIMPA  + /:id/hapus, /hapus-semua, balasan JSON (tanpa redirect)
  helpers/notificationHelper.js      TIMPA  + deleteNotification, deleteAllNotifications, createNotificationOnce

  Di dropdown lonceng sekarang bisa, TANPA pindah/buka halaman lain:
   - klik item  -> otomatis ditandai dibaca lalu menuju tautannya
   - tombol X (muncul saat disentuh/di-hover) -> hapus satu notifikasi
   - "Tandai dibaca" -> semua dibaca, badge merah langsung hilang
   - "Bersihkan" -> klik 1x berubah "Yakin? Klik lagi" (3,5 dtk), klik lagi -> semua terhapus
   - waktu relatif ("5 menit lalu"), titik biru untuk yang belum dibaca, ikon warna per jenis

C. HALAMAN PRATINJAU DOKUMEN / PDF (baru)
  routes/pratinjau.js                BARU   GET /pratinjau?u=<tautan berkas>&t=<judul>&k=<kembali>
  views/pratinjau.ejs                BARU   toolbar: Kembali | Tab baru | Cetak | Unduh + penampil dokumen
  app.js                             TIMPA  hanya +1 baris: app.use('/pratinjau', require('./routes/pratinjau'));
                                            (bila app.js sudah Anda ubah, cukup tambahkan baris itu di bawah mount '/notifikasi')
  routes/mahasiswa/surat.js, routes/dosen/surat.js   TIMPA  /:id/download kini membuka pratinjau, bukan langsung ke file
  views/mahasiswa/krs_print.ejs      TIMPA  tidak lagi langsung membuka dialog cetak (tombol "Cetak" tetap ada)
  + 48 file views/**.ejs: tautan "Lihat / Buka / Unduh PDF" ke file Drive (surat, SK, laporan magang,
    KRS/KHS, sertifikat, modul, tugas, RPS, ELK Library, akreditasi, dll.) kini lewat /pratinjau.
    Perubahannya hanya pada atribut href: href="/pratinjau?u=<%= encodeURIComponent(x.fileUrl) %>"

Keamanan /pratinjau: tidak memberi akses baru. Hanya ID berkas Google Drive yang valid (ditampilkan lewat
penampil resmi Drive, tunduk pada izin berkas itu sendiri) atau berkas /uploads & /dokumen milik situs yang
diterima. Tautan lain TIDAK pernah di-redirect otomatis (hanya tombol "Buka tautan asli" yang diklik pengguna).
Halaman ini sengaja publik agar perpustakaan ELK & dokumen publik tetap bisa dilihat tanpa login.

Tidak diubah (memang berkas data, tidak punya tampilan): ekspor Excel/CSV (PMB, tagihan, EDOM, nilai, laporan awal
semester, dll.) dan unduhan Word (.docx) SK PA / Penyelesaian Studi. Halaman cetak HTML (logbook, KHS, transkrip,
EDOM, SK, dll.) sudah berupa halaman pratinjau dan hanya mencetak bila tombol Cetak diklik.


D. NOTIFIKASI NILAI UNTUK MAHASISWA (baru)
  helpers/nilaiNotifHelper.js        BARU
  routes/dosen/index.js              TIMPA  tugas dinilai (/pengumpulan/nilai & /tugas/nilai-langsung)
  routes/dosen/mk.js                 TIMPA  LKM praktikum diperiksa

  routes/admin/rubrik.js             TIMPA  kunci nilai akhir (satu mahasiswa & "Kunci Semua")
  routes/admin/nilai.js              TIMPA  input nilai akhir manual oleh admin
  (routes/admin/emagang.js - nilai akhir magang - sudah termasuk di bagian B)

  Setiap file rute hanya bertambah 1 baris require + 1-3 baris nilaiNotif.xxx(...) (tanpa await).
  Nilai akhir memakai ID deterministik: menekan "Kunci semua" berulang tidak menggandakan notifikasi;
  notifikasi baru dikirim lagi hanya bila nilainya berubah.
  TIDAK dinotifikasi (sengaja, karena auto-simpan saat mengetik = bisa puluhan notifikasi): nilai tugas manual
  di halaman Rincian Tugas dan komponen rubrik (kehadiran/sikap/keaktifan/kuis/UTS/UAS).
