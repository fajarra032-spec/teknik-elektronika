PATCH PERBAIKAN REKAP BEBAN DOSEN (versi 5)
===========================================
File (letakkan di folder yang sama di proyek):

  data/jadwalBebanDosen.js                    BARU
  helpers/namaDosen.js                        BARU
  helpers/laporanAwalSemesterHelper.js        TIMPA
  routes/admin/laporanAwalSemester.js         TIMPA
  views/admin/laporan_awal_semester.ejs       TIMPA
  scripts/cek-sks-mk.js                       BARU   diagnostik SKS (read-only)
  scripts/perbaiki-sks-mk.js                  BARU   merapikan 3 dokumen MK yang tidak konsisten
  scripts/gabungkan-dosen-aman.js             BARU   gabung Rismawati + Sarifuddin
  scripts/sinkron-beban-dosen-dari-jadwal.js  BARU / TIMPA  (default --sks=sistem; konflik -> nilai terbanyak)

URUTAN
  1. Salin semua file.
  2. node scripts/perbaiki-sks-mk.js              <- dry-run
     node scripts/perbaiki-sks-mk.js --confirm
  3. node scripts/cek-sks-mk.js                   <- harus tidak ada lagi temuan no. 1-3
  4. node scripts/gabungkan-dosen-aman.js         <- dry-run
     node scripts/gabungkan-dosen-aman.js --confirm
  5. node scripts/sinkron-beban-dosen-dari-jadwal.js              <- dry-run, baca "SKS yang dipakai vs sumber lain"
     node scripts/sinkron-beban-dosen-dari-jadwal.js --confirm
  6. RESTART server, buka /admin/laporan-awal-semester, Ctrl+F5.
