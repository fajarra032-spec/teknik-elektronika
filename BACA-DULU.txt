PATCH FORMAT LOGBOOK MINGGUAN (1 lembar = 1 minggu)
===================================================
File (timpa di folder yang sama pada proyek):
  helpers/logbookPrintHelper.js           TIMPA
  views/mahasiswa/magang/print.ejs        TIMPA

Cukup 2 file ini: cetak mahasiswa, dosen PA, dan admin semuanya memakai template yang sama.
Tidak ada perubahan database. Restart server, lalu uji dari tombol cetak logbook.

Data opsional (bila belum ada, kolom/baris dicetak kosong untuk ditulis tangan):
  - logbookMagang.hasil            -> kolom "Hasil pekerjaan" (cadangan: field keterangan)
  - masukanLogbook tipe 'kompetensi' -> Ringkasan: kompetensi/keterampilan
  - masukanLogbook tipe 'kendala'    -> Ringkasan: kendala dan penyelesaian
  - masukanLogbook tipe 'pendamping' -> Catatan Pendamping Lapangan (sudah ada)
